## 第一步：用 Agent 自动化应用创意和验证

99%的人在应用开发之旅刚开始就失败了。

他们脑子里冒出一个小想法，花4个月时间打造梦想中的应用，完善每一个按钮和颜色……然后上线发布。

结果只有两个人下载了——你妈和你自己。这是你能做的最蠢的事。

在让 Agent 写任何一行代码之前，你需要选定一个细分领域，验证你的应用创意，确保人们真的想要它。

以下是我构建每一款应用时遵循的流程：

首先，找到一个痛点。

找到人们每天都在挣扎的问题，然后用一款应用去解决它。你可以发给 Agent 一些例子来帮你调研。

一旦我们有了要解决的问题，Eddie（我们的 Open Claw Agent）会自动完成所有调研工作。

如果你还没有搭建 Open Claw，这里有一份3分钟搞定的指南。

我们让 Eddie 去访问 screensdesign.com，基本上就是查看一些竞品应用，然后下载收入排名前三的应用的引导流程。你需要配置浏览器控制功能，否则就手动操作。

Eddie 会下载它们的引导流程，然后给我们返回引导流程的结构，以及一个 prompt，用于基于这个细分领域排名前三应用的组合来创建一套全新的设计。

这非常理想。如果你确定自己在一个好的细分领域，并且你的引导流程很给力，只要你能给应用带来关注度，你就会赚很多钱。

但如果你给应用带来了关注度，而引导流程却很烂，你大概率会失望。

这就是为什么这一步如此重要。

所有大型应用通常遵循相同的结构，跟 Cal AI 以及所有百万美金级别应用用的是一样的。

他会用它来抓取竞品的所有1星差评，然后给你一份方案，告诉你如何让应用更加脱颖而出。

所以当我们开始构建的时候，我们已经有了引导流程结构、一个设计 prompt、以及一个基于竞品差评的竞争壁垒。

所有这些都经过了已经在赚钱的应用的验证。

## 第二步：用 Rork 构建你的应用

2026年构建一款应用简直是个笑话，真的。从来没有比现在更容易的时候了。

如果你正确地完成了上一步，你的 Agent 应该已经给你发了一个 prompt，你可以连同一些参考截图一起发给 Rork。

Rork 是目前世界上排名第一的应用构建工具，它能在2-3次点击内直接发布到 App Store。

构建优秀应用的关键在于 prompt。如果你发一个模糊的 prompt，结果远不如你发一个基于参考图片的详细 prompt 来得好。

比如，我用 Rork 一次性搞定了这个应用，而我用自己 vibe coded 应用录的视频在 X 上获得了100万播放量。

它就是用上面描述的流程做出来的。

在使用 Rork 时，配合 prompt 附上图片非常重要，这样才能获得最佳效果。

所以工作流是这样的：

首先把所有参考图片发给 ChatGPT，配上下面的 prompt，ChatGPT 会输出一个超长的 prompt，告诉你如何用 Rork 能理解的方式复现你发送的参考图片。

然后你把 ChatGPT 给你的 prompt 发给 Rork，同时附上你的参考图片。几分钟之内你就会有一个可运行的应用。

你还可以从 Pinterest、Dribbble 和竞品那里获取更多设计灵感，然后对新功能重复这个 prompt 流程，直到完成你的应用。

当应用看起来很精致的时候，直接加个付费墙。我用的是 SuperWall 或者 RevenueCat，两者差别不大。

然后提交到 App Store，确保你把这些审核指南发给你的编码 Agent，避免被拒：

https://developer.apple.com/app-store/review/guidelines/

我和 @maubaron 刚刚按照这些步骤发布了一款新应用，叫 Steplock，已经在 App Store 上线，已经开始赚钱了。

## 用 Agent 自主化营销你的应用

一旦你的应用上了 App Store，就该赚钱了。而钱跟着注意力走。

我之前写过另一篇文章，讲如何用传统方式营销你的应用。但在这篇文章里，我们讨论的是如何用 Agent 来营销。

如果你想看那篇文章，链接在这里：https://x.com/ErnestoSOFTWARE/status/2014110519913857122

在你自动化任何事情之前，你需要理解5大主要营销渠道是什么以及它们如何运作，否则你不会知道该做什么以及如何实现病毒式传播。

1. UGC（需要花钱）

UGC 代表用户生成内容。基本上就是雇佣大学生每月发布30到60条视频。UGC 的核心就是量。

我通常每条视频付10-15美金，外加播放量绩效奖金。

2. 网红合作（需要花钱）

这是我最喜欢的方法之一，因为一个好的网红真的能直接带飞你的整个应用。

我按照 1美金 CPM 来雇佣网红，意思是每1000次播放付给他们1美金。

如果他们表现不好，你不会亏钱。如果他们爆了，你会获得大量应用销售。

他们比 UGC 更适合快速病毒式传播，但通常更贵也更难谈下来。

根据我的经验，100万播放量 = 2000到5000美金的收入，取决于你的应用细分领域和引导流程。

另外，CPM 交易设置上限为1000美金。

3. 无脸内容（免费）

最被低估的方法。而且大多数人完全搞砸了。

上面是一个 TikTok 账号的例子，我们用它来营销我的一款应用，由我的联合创始人运营，每月能获得数百万播放量。

无脸内容非常简单。你要做的就是找到一个爆款格式，然后无限复制它。

尽量让你的主页看起来和上面的图片一样统一。如果你的无脸账号看起来像随机的 Pinterest 图片转储，那你就完了。

4. 创始人出镜内容（免费）

拿起手机拍内容。找到一个爆款格式，然后加入你自己的风格。

我自己也这样做过。我找到了一个爆款格式，复制了它，用2条 Reels 获得了270万播放量。

如果你没钱投入到创作者身上，你也应该在制作创始人出镜内容。

它能培养你的病毒式传播直觉，以后你可以把这种感觉教给你的创作者。

5. 付费广告（需要花钱）

付费广告是最好的增长渠道。因为一旦你找到了好的创意素材，不管是来自网红、UGC 还是创始人出镜内容，你都可以把它们投放到广告里。一旦你获得了好的 CPA（获客成本），并找到几个效果好的创意素材，你就可以无限扩张。

我和 @maubaron 的大部分应用纯粹靠付费广告来扩张。

要大规模运营一个真正的无脸内容矩阵，你要么花每月3万美金雇一个代理机构，要么自己每天花8小时做。

这两个选择都很糟糕。

所以我们做的是找到了几个爆款无脸账号，让 Eddie 研究它们。
