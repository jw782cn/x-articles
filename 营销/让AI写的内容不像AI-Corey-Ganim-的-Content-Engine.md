## 架构：一个 Agent，多个 Skills

OpenClaw 是一个开源 AI agent 平台。你可以把它理解成 AI 助手的操作系统。Claire 在我的机器上 24/7 运行，连接着 Discord、Gmail、Google Calendar 和我的文件系统。

真正的威力来自 skills。Skills 是 markdown 指令文件，教 agent 如何精确完成某个具体任务。不是模糊的 prompt，而是详细的、一步步的工作流，包含格式规则、语气指导和质量检查。

## 引用推文机器

引用推文是目前 X 上杠杆最高的内容格式。原因是：你在借用别人的受众，同时在上面叠加原创价值。

我的流程：

我刷 X 5-10 分钟，找到在 AI/商业领域获得关注的推文。可能是一个爆款 thread、一个工具发布、一个犀利观点。我复制 URL，在 Discord 里发给 Claire：

"写一条战术性引用推文，拆解怎么把这个变成一门生意。"

或者："用我们的视角写一条引用推文。"

Claire 读取原始推文（她有浏览器权限），提炼核心洞察，然后起草一条增加战术价值的回复。不是 "好推文"，不是简单的反应。而是一个编号拆解、一个反直觉观点、或者一个步骤式指南。

我最近发的一条引用推文，拆解了如何把 Kevin O'Leary 关于获客的视频片段变成一个年收入 25-50 万美元的 AI 生意。那条推文获得了 47.1 万浏览和 7600 收藏。

关键：让引用推文本身就有价值。即使别人从不点原文，他们也应该学到东西。

## X 长文工作流

X 长文是原生在 X 上的长篇内容，像普通推文一样在信息流中分发，但可以达到 700-1000+ 词。

我的 skill 一次搞定整个工作流：

Step 1：选题。 我要么给 Claire 一个具体话题，要么她用 last30days skill 研究当前趋势，从 Reddit、X 和互联网上拉取真实对话。

Step 2：正文。 700-1000 词，战术格式。5-10 条编号列表，每条有标题、解释和具体细节。每个部分都应该是读者可以落地执行的。

Step 3：开头 + CTA。 一个制造好奇心缺口的 hook，1-2 句背景，以及一个链接到引流品的行动号召。

Step 4：标题。 Claire 生成 7 个标题选项，使用经过验证的模式：数字、括号钩子、好奇心缺口、具体的时间/金额声明。我选感觉最对的那个。

Step 5：缩略图。 她构建 3 种不同的缩略图设计，用 HTML 文件生成，用 headless Chrome 以 1250x500（X 长文要求的 5:2 比例）渲染，交付 PNG。

从选题到可发布的文章（含缩略图），我的主动投入时间大约 10 分钟。大部分时间花在审阅和选标题上。

## YouTube 到 X 的管线

每期播客都会变成 X 内容。录完节目后，我把文字稿发给 Claire，她提炼出最有战术价值的单个洞察，写一条推广推文。

规则是：用战术内容开头，而不是视频公告。"新一期上线了！" 没人看。"大多数小企业每月花 5000-10000 美元请营销公司。我们在一次 session 里用 Claude Code 替换了整个技术栈" 会被收藏。

单凭这一个 skill，就为原本只能获得一小部分流量的节目带来了数千次浏览。

## CTA 系统

每条高表现推文都会附一条 CTA（行动号召）回复。我有一个专门的 skill 来做这件事：

CTA 始终把推文话题和具体结果关联起来。如果推文讲的是替代 SaaS 工具，CTA 就提到构建 AI 替代品。如果讲的是工作流，CTA 就指向我教这个工作流的社区。

不是 "关注获取更多"，而是 "如果你真想做这件事，下一步在这里。"

## 研究层

last30days skill 是一切的基础。写文章之前，我可以研究过去 30 天里人们在 Reddit、X 和互联网上真正在讨论什么。

它返回的是具体帖子、互动数据和模式。不是泛泛的总结。而是真实的帖子（带点赞数）、推文（带收藏数）和博客文章。Claire 综合所有内容，找出 3-5 个最强信号。

这意味着我写的每篇文章都扎根于受众当下关心的东西。不是我觉得他们关心什么，而是他们真正在讨论、收藏和分享的内容。

## 没人告诉你的事

它会复合增长。 我建的每个 skill 都让 Claire 更强。Brand voice 档案意味着她从第一天就像我。CTA 范例文件每次我们发现新的有效格式都会更新。文章 skill 每次我给反馈都会被优化。

它很快。 我每天可以产出 3-5 条高质量内容，主动工作时间大概 30-45 分钟。其余时间是 Claire 在执行 skills，我做别的事。

它很稳定。 Claire 没有状态不好的日子。她不会忘记格式规则。她不会偏离我的语气。Skills 每次都强制执行质量标准。

它可移植。 每个 skill 就是一个 markdown 文件。我可以分享、出售，或交给团队成员。
