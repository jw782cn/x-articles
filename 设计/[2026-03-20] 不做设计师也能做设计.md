# [2026-03-20] 不做设计师也能做设计

**原文链接**：[https://x.com/neethanwu/status/2034786360356204934](https://x.com/neethanwu/status/2034786360356204934) by @neethanwu

43万阅读 | 1047点赞 | 3858收藏

我是一个工程师，三个月前从未接触过 UI/UX 设计。后来我搭了一套用于设计的 Agent 工具链，让我能够独立完成从设计到交付的全流程。

Agent 正在改变一个人能覆盖的能力范围。我一直在往全栈方向推进自己，去啃以前啃不动的领域。设计是最大的那块。像素、间距、字体、配色——这些东西决定了用户在读到第一个字之前，是否就已经信任你的产品。

我从来不具备这方面的能力。所以我搭建了一套设计工具链：**三个层次**，让我拥有真正的设计能力，而不需要自己变成设计师。

下面是具体内容。

---

## 第一层：Skills（专业能力）

Skills 是你安装到 AI Agent 里的指令文件，不管你用的是 Claude Code、Cursor、Codex 还是别的什么。它们把别人的设计经验注入你的工作流。本质上，你是在**借用资深设计师的审美**。

### Impeccable（@pbakaus）

这是我用得最多的 skill，作者是 jQuery UI 的原始创建者。它有 20 多个命令：/audit、/polish、/animate、/typeset、/arrange。它能抓住那些让 AI 生成的 UI 一眼看上去就像 AI 做的反模式：滥用的字体、灰色叠在彩色上的文字、纯黑色、嵌套卡片。

[图片]

**/delight** 是我目前最喜欢的命令。我经常用，每次它都会带来让我惊艳的东西，整体提升产品的质感。这一个 skill 基本上一夜之间改变了我的设计产出。

### Emil Kowalski 的 Design Engineer Skill（@emilkowalski）

Emil 是 Linear 的设计工程师，之前在 Vercel，创建了 Sonner 和 Vaul（两个库的 npm 周下载量合计超过 1500 万）。他的 skill 把他对动画、UI 细节打磨以及大多数人忽略的小细节的思考方式编码了进去。我用免费版来短暂借用 Emil 的思维方式，偶尔把他的思考方式应用到我的设计工作中。完整版附带他的 animations.dev 课程。

### Interface Design（@Dammyjay93）

这个解决了 AI 辅助设计中最烦人的问题：**你的 Agent 在不同会话之间会忘掉所有的设计决策**。这个插件把你的规范（间距网格、调色板、层次策略、组件模式）存储在一个持久化的 system.md 文件中，自动加载。

### UI Skills（@ibelick）

由 Julien Thibeaut 创建，他也是 motion-primitives 的作者。15 个开源 skill，覆盖基础 UI、无障碍、动效性能和元数据。作为广泛覆盖的基础很扎实。我用得不如 Impeccable 频繁，但需要的时候它就在那里。

## 第二层：Agent Canvas（设计画布）

我也把这些叫做 Agent Shell。它们是没有内置 Agent 的设计画布，使用的是你自己的 Agent——Claude Code、Codex，或者你本地跑的任何东西。**Canvas 是外壳，你的 Agent 是内核。**

### Paper（@paper）

这是我最近用得更多的一个。画布基于真实的 HTML 和 CSS 构建，不是什么私有格式。你设计的东西就是实际的代码，**没有转换层，没有交接成本**。

[图片]

它暴露了带有完整读写权限的 MCP 工具。由于不需要格式转换，开箱即用就能和本地 Agent 配合良好。大多数时候我用 Paper 来做设计系统、设计 token 和页面设计迭代，然后在构建产品的同时把它作为设计的唯一真实来源和参考。Paper 有免费层，但 MCP 调用次数有限制。

### Pencil（@tomkrcha）

走了一条不同的路。它使用基于 JSON 的 .pen 格式，支持 Git diff，Agent 可以通过 MCP 操作。我的设计文件放在代码仓库里，像代码一样做版本管理。

[图片]

Pencil 还有一个 **Swarm 模式**，我可以同时启动多个 Agent（最多六个）在画布上工作：一个负责字体排版，一个做布局，第三个传播设计系统。第一次看到 Agent 集群在我的画布上同时视觉化工作时，我被震撼到了。

Pencil 目前免费，我同时在用 Pencil 和 Paper。

## 第三层：灵感与审美（设计之眼）

Skills 给了我专业能力，Canvas 给了我工作台面。但我还需要训练自己的眼睛——在让 Agent 去做之前，我得先知道什么是好的设计。

### Variant（@variantui）

输入一个想法，无限滚动浏览不重复的设计诠释。最突出的功能是 **Style Dropper**：你把它对准任意一个设计，它会吸收其视觉 DNA（调色板、字体节奏、空间密度），然后迁移到另一个设计上。

[图片]

### Mobbin（@mobbin）& Awwwards（@awwwards）

这两个在设计圈已经知名很久了。我用它们来吸收最好的、最精选的设计作品，从中学习审美。

**Mobbin** 覆盖移动应用和网站。当我需要看顶级应用怎么处理引导流程、设置页或结账流程时，就去那里。他们最近发布了一个 Figma 插件，可以直接拉取参考，不过我不用 Figma（不会用），也没测试过。

**Awwwards** 有专业评审团打分，覆盖 Web 设计的前沿。他们也办大会和学院。

### Cosmos（@thecosmos）

这是我收集所有灵感和想法、探索他人合集的地方。网页设计、室内设计、字体、摄影、建筑，只要抓住我眼球的东西都往里放。

我不断通过他们的十六进制颜色搜索甚至模糊描述来发现新东西。它找到我想要的东西的方式至今仍让我惊喜。我用它来构建视觉参考的集群，慢慢塑造我对设计的思考方式。

## 整体模式

**三个层次**：Skills 提供专业能力。Canvas 让 Agent 有地方干活。灵感训练你的眼睛。

我不是设计师。我没有多年训练出的直觉，审美还在成长中，每天都在学习。但我解锁了自己。我从完全不会做设计，到每周都在交付设计，并且对自己产出的东西还算满意。三个月前，这一切都不存在。

**你不需要成为设计师。你需要的是一套合适的工具链。**
